Week 1 correctness check: run the pretrained PointPillars checkpoint on KITTI val (no training). Inference finished (3769 samples, checkpoint 127/127 loaded, wrote result.pkl) then crashed with Segmentation fault during official KITTI AP scoring. The dtype tensor line was only a warning. The real failure was the grader, not the detector.

Root cause: OpenPCDet's stock eval uses numba.cuda in
OpenPCDet/pcdet/datasets/kitti/kitti_object_eval_python/rotate_iou.py
That CUDA IoU kernel segfaults on this WSL setup even though torch CUDA works. Confirmed with:
python -c "from pcdet.datasets.kitti.kitti_object_eval_python.rotate_iou import rotate_iou_gpu_eval; import numpy as np; a=np.array([[0,0,1,1,0]], dtype=np.float32); print(rotate_iou_gpu_eval(a, a))"
-> Segmentation fault

Fix: rewrote rotate_iou.py on Windows to keep the same public API (rotate_iou_gpu_eval) but compute rotated-box IoU with CPU numba instead of numba.cuda. This is an eval-only change for our system; the detector weights and inference path were not rewritten. Copied the fixed file into the Ubuntu clone:

cp "/mnt/c/Users/zackw/OneDrive/Desktop/DirectedIndipendentStudy/OpenPCDet/pcdet/datasets/kitti/kitti_object_eval_python/rotate_iou.py" ~/OpenPCDet/pcdet/datasets/kitti/kitti_object_eval_python/rotate_iou.py

python -c "from pcdet.datasets.kitti.kitti_object_eval_python.rotate_iou import rotate_iou_gpu_eval; import numpy as np; a=np.array([[0,0,1,1,0]], dtype=np.float32); print(rotate_iou_gpu_eval(a, a))"
-> [[1.]]

Then scored the already-saved predictions (no second detector pass) from tools/:

python <<'EOF'
import pickle
from pathlib import Path
from pcdet.config import cfg, cfg_from_yaml_file
from pcdet.datasets.kitti.kitti_dataset import KittiDataset

cfg_from_yaml_file('cfgs/kitti_models/pointpillar.yaml', cfg)
dataset = KittiDataset(
    dataset_cfg=cfg.DATA_CONFIG,
    class_names=cfg.CLASS_NAMES,
    root_path=Path('../data/kitti'),
    training=False,
    logger=None,
)
det_annos = pickle.load(open(
    '../output/kitti_models/pointpillar/default/eval/epoch_7728/val/default/result.pkl',
    'rb',
))
result_str, result_dict = dataset.evaluation(
    det_annos, cfg.CLASS_NAMES, eval_metric='kitti',
)
print(result_str)
EOF
